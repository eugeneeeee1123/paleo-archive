PROJECT INTRODUCTION / 网站简介

ABOUT THIS ARCHIVE

A prehistoric life and deep-time geology archive built as a front-end web development project.

Paleologist brings together fossil records, deep-time geological eras, and specimen profiles. The visual style takes inspiration from natural history museum catalog cards and field expedition computer displays.

The site was built with plain HTML, CSS, and vanilla JavaScript without external UI frameworks or libraries. All species metrics are stored in a single JavaScript file, while user preferences and lab creations are saved in browser storage.

这是我在前端课程中的期末大作业，主要围绕古生物与地质年代展开。页面结合了自然博物馆展品标牌与野外科考站终端的视觉风格。

全站使用原生 HTML、CSS 与 JavaScript 构建，没有引入第三方前端框架。古生物体型与年代数据参考了国际地层委员会（ICS）年表与公开古生物文献，自制记录则保存在浏览器的本地存储中。
